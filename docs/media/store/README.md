# Store and social media

Generated by `tools/docs/gen_store_media.py` from real captures plus the key art.

| File | Use |
|---|---|
| `pt_BR/appstore/*.jpg`, `en/appstore/*.jpg` | App Store, 6.7" (1290×2796) |
| `pt_BR/play/*.jpg`, `en/play/*.jpg` | Google Play phone (1080×1920) |
| `feature_graphic_1024x500.jpg` | Google Play feature graphic |
| `*/social_1920x1080.jpg` | Reddit, X, YouTube/itch covers |
| `*/social_1080x1080.jpg` | Instagram / Reddit gallery |
| `*/header_1500x500.jpg` | X/Twitter header |
| `*/og_1200x630.jpg` | Link preview; `pt_BR` is copied to `landing/assets/og.png` by `gen_landing.gen_og` |
| `brand/logo_transparent.png` | The STACKYARD logo cut out of its magenta ground |
| `brand/logo_crane.png` | The logo lifted by a whole ship-to-shore crane — bogies on a railed quay, braced portal, A-frame and stays, a boom with a finished nose (`tools/docs/gen_brand_logo.py`) — the one the media uses. The steel is drawn finer than the letters (`SCALE`) so the word is most of the lockup |
| `keyart/` (PNG): `logo`, `icon`, `keyart_wide`, `keyart_square` | Model-generated key art + `generations.json` (prompt, refs, cost) |

The English set has four screens instead of six on purpose: shop item names and
port taglines are not translated yet (handoff R1), and a store screenshot in
English must not show Portuguese copy. Add the shop and globe back once R1 lands.

Regenerate:

```bash
godot --path . --audio-driver Dummy tools/capture/closeup.tscn -- lang=pt_BR "ship+wake_trail+shop_upgrades+ports+landworks"
godot --path . --audio-driver Dummy tools/capture/closeup.tscn -- lang=pt_BR decor_night
godot --path . --audio-driver Dummy tools/capture/closeup.tscn -- lang=en "ship+wake_trail+rail+decor_night"
tools/venv/bin/python tools/docs/gen_brand_logo.py
STACKYARD_SHOTS_PT=... STACKYARD_SHOTS_EN=... tools/venv/bin/python tools/docs/gen_store_media.py
```

`gen_store_media.py logo` redoes only what carries the lockup (the first screen
of each set, the banners, the feature graphic) when the logo changed and the
other captures did not; it needs just `closeup_ship.png` per language.

(copy each run's `user://uishots/closeup_*.png` into its language folder first.)
The key art only changes when `gen_keyart.py` is re-run with an OpenRouter key.

Copy is set in the game's bitmap font (`assets/fonts/harbor_font`), which has no `&` or `…`.
OpenRouter refuses image output once a key has less than $1.00 left.

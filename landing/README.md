# Landing page

Static front door for the public Web release. The landing lives at `/`; the
Godot export lives at `/jogar/`. `tools/export/build_release.sh` assembles both
surfaces under `build/release/`, copying `landing/assets/*` to `/media/`.

It has no framework, no build step and no third-party request: three files plus
the sprites and two self-hosted pixel fonts. The Web server must still send the
COOP/COEP/CORP headers documented in `docs/architecture/testing-release.md`,
because the game shares this origin.

## Art

Every image here is generated by `tools/sprites/gen_landing.py` — the wordmark,
the mirrored title backdrop, the seamless water and road, the rigs, the
nine-slice chrome, the marks and the social card. Do not edit the PNGs by hand:
change the generator and run

```bash
tools/venv/bin/python tools/sprites/gen_landing.py
```

Sprites the page borrows from the game (crane, ship, containers, seagull, cat,
world map, anchor) are copied by the same script, so the front door can never
drift from the terminal behind it.

## Pixel discipline

Nothing is upscaled on disk. `styles.css` holds a set of integer scale
variables — `--s` art, `--k` chrome, `--ls` wordmark, `--ai` card art, `--ds`
small props, `--ws` water and road, `--bs` the boat — and every sprite is sized
as `native × scale`, so a source pixel is always a whole number of screen
pixels. A fractional scale anywhere is a bug.

Press Start 2P carries display type and Pixelify Sans the body text, both
self-hosted from `assets/*.woff2` (SIL Open Font License). Neither font has
play, chevron, diamond, arrow, tick or cross glyphs, so those are drawn in
`marks.png` and applied as CSS masks that inherit `currentColor`.

## Preview

The page uses absolute `/media/...` paths, so open it through a server that
mirrors the release layout rather than from the file system:

```bash
tools/export/build_release.sh && (cd build/release && python3 -m http.server 8765)
```

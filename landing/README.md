# Landing page

Static front door for the public Web release. The landing lives at `/`; the
Godot export lives at `/jogar/`. `tools/export/build_release.sh` assembles both
surfaces under `build/release/`, copying `landing/assets/*` to `/media/`.

It has no framework, no build step and no third-party request: four files plus
the sprites and the self-hosted pixel fonts. The Web server must still send the
COOP/COEP/CORP headers documented in `docs/architecture/testing-release.md`,
because the game shares this origin.

## Art

Every image here is generated by `tools/sprites/gen_landing.py` — the wordmark,
the mirrored title backdrop, the seamless water, road and skyline, the ship,
the rigs, the nine-slice chrome, the marks, the card badges and the social
card. Do not edit the PNGs by hand: change the generator and run

```bash
tools/venv/bin/python tools/sprites/gen_landing.py
```

Sprites the page borrows from the game (crane, containers, cat, world map,
anchor) are copied by the same script, so the front door can never drift from
the terminal behind it.

**The gulls are drawn here too.** `prop_seagull` is seen from directly above,
because that is the angle the game is played at; crossing a hero in front of a
side-on ship and a side-on sea, a bird seen from above reads as a little person
holding its arms out. `GULL_FRAMES` draws four side-on frames of one flap
instead, each frame whole rather than a body with a wing pasted onto it — at
sixteen pixels the join is most of the bird.

**The ship is drawn here, not borrowed.** The hero used to reuse `ship_cute`,
the game's little top-down harbour boat, which on a wide screen read as a bath
toy crossing a container terminal. `_draw_ship()` draws a side-on container
vessel instead — hull, forecastle, accommodation block, funnel and a stack of
the game's own boxes — and the same routine produces the small feeder on the
first card, with three bays instead of six. Both ship in three-frame strips:
bow wave, wash and funnel smoke are stepped by CSS, never cross-faded, because
a pixel ship with soft edges is not a pixel ship. The strip carries
`SMOKE_ROOM` blank rows above the funnel — without them the plume ran into the
top edge of the sprite and came out flat.

## Favicon

`gen_favicon()` draws an amber badge with the harbour's anchor cut out of it at
16px and scales it by whole numbers only: `media/favicon.png` (32),
`media/favicon-192.png` for `apple-touch-icon`, and `favicon.ico` carrying 16,
32 and 48. A badge rather than a bare anchor because a thin silhouette on
transparency disappears into whatever colour the browser paints behind the tab,
and it has to read on light chrome and dark chrome both.

`favicon.ico` sits next to `index.html` rather than in `assets/`, and
`build_release.sh` copies it to the release root: a browser asks for
`/favicon.ico` whether the page links it or not, and nginx's catch-all would
otherwise answer that request with the whole HTML document.

## Pixel discipline

Nothing is upscaled on disk. `styles.css` holds a set of integer scale
variables — `--s` art, `--k` chrome, `--ls` wordmark, `--ai` card art, `--ds`
small props, `--ws` water and road, `--bs` the ship, `--sk` the skyline — and
every sprite is sized as `native × scale`, so a source pixel is always a whole
number of screen pixels. A fractional scale anywhere is a bug.

Press Start 2P carries display type and Pixelify Sans the body text, both
self-hosted (SIL Open Font License). Neither font has play, chevron, diamond,
arrow, tick or cross glyphs, so those are drawn in `marks.png` and applied as
CSS masks that inherit `currentColor`.

## Fonts

Nine languages need more than the Latin-1 subsets the page used to ship: a
glyph a font does not have renders as nothing at all. `tools/fonts/build_landing_fonts.py`
fetches the Latin, Latin Extended and Cyrillic subsets of both families and
writes them into `assets/`, and `styles.css` declares a `unicode-range` per
file so a Portuguese reader still downloads only the Latin one.

```bash
tools/venv/bin/python tools/fonts/build_landing_fonts.py
```

It also repairs two published defects, which is why the files are built rather
than downloaded:

- Pixelify Sans's Cyrillic subset ships without **U+041E О** and **U+041F П** —
  two of the commonest letters in Russian. О is copied from the Latin O; П is
  drawn on the stem and bar metrics the font's own Н and Г already use.
- Press Start 2P draws **U+0130 İ** with a stem only 71% of cap height, so
  Turkish `LİMAN` reads as `LiMAN`. The stem is redrawn at 85% and the dot
  slimmed to match, all still inside the em box.

Run the script again after either font is updated upstream.

## Languages

`i18n.js` holds the page in the same nine languages the game speaks, in the
same shape as `scripts/i18n/strings_ui.gd`: one row per key, one column per
language, nothing fetched at runtime. Markup carries `data-i18n="key"`.

The picker writes `harborclick.lang` to localStorage; with nothing stored,
`navigator.languages` decides — the same rule as the game's `Loc` autoload,
where "follow the device" is the default rather than the absence of a choice.
`?lang=en` overrides both, so a link can point at one language, and so a
screenshot pass can walk all nine.

`tools/qa/check_landing_strings.py` runs in `run_all.sh` and fails the build if
a key is in the markup but not the table, in the table but used by nothing, or
short a language. A missing key is not a blank label here: `t()` returns the
key, so the front page publishes the literal text `yard.2.body`.

**On the copy.** This is one person's small game, and the page should sound
like it: short lines, plain words, no manifesto. If a sentence could appear in
a press release it is wrong. The ticker is the night shift talking to itself
rather than a feature list, the deal is four words each, and the last card is
about the cat.

## Preview

The page uses absolute `/media/...` paths, so open it through a server that
mirrors the release layout rather than from the file system:

```bash
tools/export/build_release.sh && (cd build/release && python3 -m http.server 8765)
```

Then photograph it with `tools/qa/shoot_landing.py`, which drives CDP and calls
`Emulation.setDeviceMetricsOverride`. Do not reach for
`chrome --headless --window-size=390,844`: it silently renders at a 500px floor
and then crops the PNG to the size you asked for, which looks exactly like a
broken mobile layout.

```bash
tools/venv/bin/python tools/qa/shoot_landing.py http://127.0.0.1:8765/ shots \
    phone:390x844 desktop:1440x900:w=20 wide:1920x1080:w=26 \
    ru:1440x900:L=ru loop:1440x900:@.bay picker:390x844:c=#lang-btn \
    reduced:1440x900:still
```

`w=` waits longer before the shutter — the ship takes about a minute to cross,
so a default-timed shot catches it half off the left edge. `@` scrolls to a
selector first, because a section whose reveal has not fired photographs
blank, and a full-page capture never scrolls at all.
